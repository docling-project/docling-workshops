# Red Hat Summit 2026 - Docling Workshops

## Overview

Join us at **Red Hat Summit 2026** for an exciting series of sessions showcasing **Docling**, the Swiss Army knife for scalable document AI! Whether you're interested in document processing, building intelligent applications with RAG, agentic AI, or large-scale data processing, we have sessions tailored for you.

Docling is an open-source toolkit that makes it easy to prepare documents for LLM applications. From parsing complex PDFs to building production-ready RAG systems, Docling provides the tools you need to transform raw documents into actionable insights. Learn how Docling seamlessly integrates with the Red Hat ecosystem—including Red Hat OpenShift AI, Red Hat AI Inference Server, and Kubernetes-native tools—to deliver enterprise-grade document intelligence at scale.

We're looking forward to meeting community members, sharing knowledge, and exploring how Docling can help solve your document AI challenges!
